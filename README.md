### 🧩 Core Components

| Component        | Technology                          | Responsibility                            |
| ---------------- | ----------------------------------- | ----------------------------------------- |
| Frontend         | Streamlit                           | User interface and interaction            |
| Video Downloader | yt-dlp                              | Downloads media from supported URLs       |
| Audio Processing | FFmpeg                              | Converts and splits audio                 |
| Speech-to-Text   | OpenAI Whisper                      | Converts speech into text                 |
| LLM              | Mistral                             | Summarization and information extraction  |
| Embeddings       | HuggingFace / Sentence Transformers | Converts transcript chunks into vectors   |
| Vector Database  | ChromaDB                            | Stores and retrieves transcript knowledge |
| RAG              | LangChain                           | Context-aware question answering          |
| Configuration    | Python-dotenv                       | Manages environment variables             |

### ⚙️ End-to-End Flow

1. User provides a **YouTube URL or uploads a media file**.
2. `yt-dlp` downloads the media/audio.
3. FFmpeg converts the audio to **16 kHz mono WAV**.
4. FFmpeg splits the audio into smaller chunks.
5. Whisper performs **speech-to-text transcription**.
6. The complete transcript is generated by combining all chunks.
7. Mistral generates:

   * Title
   * Summary
   * Action items
   * Key decisions
   * Open questions
8. The transcript is chunked and converted into embeddings.
9. ChromaDB stores the embeddings for retrieval.
10. User can ask questions through the RAG chat interface.
11. Relevant transcript context is retrieved and passed to Mistral.
12. The application returns a **context-aware answer**.

### 🎯 Key Design Goals

* Modular processing pipeline
* Local audio preprocessing with FFmpeg
* CPU-friendly Whisper transcription
* LLM-powered information extraction
* Persistent vector-based retrieval
* Context-aware conversational Q&A
* Streamlit-based interactive interface
